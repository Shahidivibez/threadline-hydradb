# Render Free demo deployment

Threadline can be deployed as two Render web services from the Blueprint in `render.yaml`:

- `threadline-app` — the Node app.
- `threadline-hydradb` — HydraDB's open-source `graph-node` image, pinned to the same `sha-9166374` engine build used for the local prototype.

The app's server-side `HYDRADB_URL` and `HYDRADB_TOKEN` are wired from the database service. The token is generated by Render and is not stored in this repository or sent to browser code.

## Deploy

1. In the Render dashboard, choose **New → Blueprint**.
2. Connect the public GitHub repository `Shahidivibez/threadline-hydradb`.
3. Review the Blueprint. Both services must say **Free**. Keep them in Frankfurt. If Render asks for payment details or proposes a paid service, stop without confirming.
4. Deploy the Blueprint and wait for both services to finish building.
5. Open the `threadline-app` service URL. Use a task such as “Find Acme’s overdue invoice and draft a follow-up.” The first task seeds the demo graph if needed.

## Free-plan limitation

Render Free services can sleep after inactivity and use an ephemeral filesystem. When HydraDB's service restarts or sleeps, its local demo graph may be cleared; the next task seeds the graph again. Expect a cold start. This is suitable for a small hackathon demo, not durable production data. The public HydraDB HTTP endpoint is protected by a server-side bearer token; do not expose or commit that token.
